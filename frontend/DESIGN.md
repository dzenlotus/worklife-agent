# Worklife composition

Visual thesis: a calm graphite working ledger for an MCP agent, using HeroUI 3 component defaults and a semantic color theme; no component, typography, radius, or shadow overrides.

Content plan: the public page explains MCP tools for job search, then shows one explicitly synthetic observer preview and the installation/stdio configuration. The local interface leads with actual MCP calls, saved results, and schedules. The existing agent owns conversation and model selection; an optional embedded runtime is confined to advanced settings.

Interaction thesis: keep HeroUI's native tabs, disclosures, navigation, and dialogs. Inspect a recorded call, follow its saved result, or review a schedule. The browser observes work and exposes occasional settings rather than competing with the agent chat. Narrow layouts remain usable without driving desktop composition.

Acceptance: inspect 1280 and 1440 px desktop renders, verify semantic foreground/background contrast, and perform a narrow-layout overflow check. Never use synthetic preview data as app state or treat review scores as targets.
