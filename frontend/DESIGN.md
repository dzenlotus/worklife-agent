# Worklife interface

A compact desktop application built from standard HeroUI 3 components. Neutral graphite surfaces and a restrained blue accent use semantic theme tokens. Component styles, fonts, radii and shadows stay native.

The application has a full-height navigation surface and a separate content region. Four everyday destinations stay visible; materials and supplementary tools use native disclosures. Long navigation scrolls within the sidebar. Each page begins with one title. Refresh metadata sits in the navigation footer.

Overview shows an even, compact activity ledger: timestamp, actual record or outcome, status, and details. Saved results link directly to their records. A single small summary contains only nonzero categories; schedules appear only when present. There is no promotional-sized latest-action card or invented activity.

Employer observations distinguish the claim, its source, date, and verification basis through standard Typography and Chip variants. Integrity information and local exclusions are disclosures.

The public page puts the product explanation and interactive synthetic search preview in one viewport. Installation, MCP configuration and the first instruction use native tabs. The shared employer database has its own concise section. Synthetic data remains explicitly labeled.

UI/UX Pro Max informs hierarchy, progressive disclosure and contrast. Its generated mobile-first, font and palette suggestions were excluded where they conflicted with the user's desktop and stock-HeroUI requirements. Only layout/accessibility utilities and semantic color tokens are used.

Verification: real sparse state and a separate populated fixture, desktop 1440/1280, keyboard navigation, result dialogs, setup tabs, and narrow overflow. Prior independent reports remain unchanged.
