# Worklife composition

Visual thesis: a calm graphite action ledger for an MCP agent, using HeroUI 3.2.6 component defaults and a semantic color theme; no component, typography, radius, or shadow overrides. Composition supplies hierarchy: the latest recorded action leads, older activity recedes into a compact ledger, and actual saved material occupies a narrow contextual rail.

Content plan: the public page pairs one clear product promise with a short three-step role explanation, then shows one explicitly synthetic observer preview and an asymmetric installation/stdio guide. The local interface leads with the human outcome of the most recent actual MCP call, its recorded result, and compact technical metadata. Saved-material summaries and schedules appear only when they contain data. The existing agent owns conversation and model selection; an optional embedded runtime is confined to advanced settings.

Interaction thesis: use HeroUI's native button variants for visibly selected grouped navigation, tabs for result filters, disclosures for setup/advanced content, and dialogs for details. Open a recorded result directly or inspect the original call and follow its saved result. The browser observes work and exposes occasional settings rather than competing with the agent chat. Narrow layouts remain usable without driving desktop composition.

Design references: UI/UX Pro Max was searched for an internal desktop operations console, then for data-dense dashboards, drill-down, monitoring, empty states and React derived data. Its conversion landing pattern, suggested light palette, custom fonts and glow effects were rejected against the product constraints. Raw recommendations and the adaptation are retained in artifacts/ui-ux-pro-designer/.

Acceptance: inspect 1280 and 1440 px desktop renders, verify semantic foreground/background contrast, and perform a narrow-layout overflow check. Never use synthetic preview data as app state or treat review scores as targets.
