## 1

Use case: ui-mockup. Asset type: high-fidelity Russian desktop website design mockup for the GitHub Pages project page of Worklife, shown straight on as a clean webpage screenshot, not a laptop photograph. Generate one polished tall desktop webpage composition, approximately 1440px wide by 1800px tall. Direction A: calm graphite and near-black surfaces, warm off-white type, one restrained amber accent, precise contemporary typography, mature product design, a large unambiguous worklife wordmark. The main idea is a personal autonomous job-search agent that chooses job aggregators, employer sites and job-search services by itself and keeps searching on a schedule. Human goals are central. Use a compact hero with the exact short headline "Поиск работы под вашим контролем." and a supporting line "Агент ищет, общается и проверяет гипотезы. Вы видите каждый шаг." Buttons "Запустить локально" and "GitHub". Navigation: "Возможности", "Приложение", "База работодателей". The dominant visual should be one large coherent desktop application workspace, integrated into the page rather than a floating card collage. In this product preview show a restrained sidebar with "Обзор", "Поиск", "Расписание", "Эксперименты", "Сильные стороны", "CV", "Работодатели", a main activity timeline with meaningful concise Russian entries, a readable job pipeline table, one subtle line chart for search statistics and a small next-run schedule area. Product preview must visibly say "Демонстрационные данные"; example stats are illustrative only. Below the preview show a crisp section "Общая база — только работодатели." and a simple company-to-company replica diagram, with no worker profiles. Personal CVs, Git repository analyses and strengths stay local. Short final start section. Important: Do NOT show a tests-passed section, HTTP errors, QA reports, tool count badges, a fixed platform integration list, named job-board brands, or marketing hype. No green earthy colors, no generic purple gradients, no stock person photos, no robot mascots, no tiny unreadable text soup, no wall of cards. Beautiful rigorous spacing, clear hierarchy and realistic buildable HTML design. This is a proposed design, not a claim that the previewed app is already implemented.
