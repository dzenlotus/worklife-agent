01 / ОТПРАВНАЯ ТОЧКА

Хорошая работа начинается
с хороших вопросов.

Не «куда бы откликнуться», а «как я хочу жить». Агент превращает ваши ответы в условия поиска и вопросы работодателю.

01

Обозначить важное

Доход, часы, место работы, этапы найма и допустимое тестовое. Ваши условия становятся точкой отсчёта.

02

Выяснить неизвестное

Нет зарплаты или непонятен график? Это повод уточнить условия, а не принять догадку за факт.

03

Действовать осмысленно

Подготовить подходящее CV, конкретный отклик и следующий шаг. Сохранить результат, чтобы к нему вернуться.

05 / ВАШ СЛЕДУЮЩИЙ ШАГ

Дайте вашему
агенту инструменты.

Нужны Python 3.12+, uv и среда агента с поддержкой MCP. Модель и доступ к нужным аккаунтам выбираете вы.

  1. 01Установите проект и Chromium.
  2. 02Укажите аккаунты в .env,
    а провайдеры — в config.toml.
  3. 03Подключите MCP и передайте
    агенту свои условия.
Пример подключения MCP ↗
Быстрый старт
git clone https://github.com/dzenlotus/worklife-agent.git
cd worklife-agent

uv sync --extra browser
uv run playwright install chromium

cp config.example.toml config.toml
cp .env.example .env

# Настройте .env и config.toml, затем:
uv run --env-file .env worklife --config config.toml mcp
↳ Запуск MCP через stdio в вашей среде агента
